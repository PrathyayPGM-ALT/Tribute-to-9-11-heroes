# Never Forgotten — 9/11 Memorial Archive

A SQL-based memorial archive created to honor and preserve the memory of the people who lost their lives on September 11, 2001, and to recognize the courage of those who responded and helped others.

The project demonstrates relational database design, foreign-key relationships, SQL aggregation, analytical queries, and database views while applying these concepts to a meaningful historical dataset.

> **"Never Forget."**

### Purpose

This project is intended as an educational programming project and a digital tribute. The information should be sourced from reliable historical and memorial institutions, particularly the National September 11 Memorial & Museum.

The database is designed to preserve names, locations, service affiliations, historical records, and remembrance messages in a structured format.

### Technologies

* SQL
* Relational database design
* Primary & foreign keys
* SQL Views
* Aggregation and analytical queries
* Data integrity constraints

### Respect

This project focuses on remembrance, the lives of those lost, the courage of responders, and the importance of preserving historical memory. It does not attempt to recreate or sensationalize the events.

**We remember.**
